# UE 工厂战术试玩

## 获取项目

本仓库的 UE 资产、贴图和音频使用 Git LFS。克隆前请安装 Git LFS，然后执行：

```sh
git lfs install
git clone https://github.com/Since2019/JD-FPS.git
cd JD-FPS
git lfs pull
```

引擎缓存、临时文件及本地运行记录不纳入版本控制，会在打开项目时重新生成。

写实制作标准现已固化到 [美术方向](ART_DIRECTION.md) 与 [资产技术卡](Unreal/FactoryRaid/Art/ASSET_SPECIFICATIONS.md)。本轮调整 PBR、局部污染、曝光和全息瞄具尺寸；专业高低模、人物/手部重制及完整性能验收仍未完成，不能视为塔科夫级成品。

新增 **CC0 枪械与扫描海岸**：双击 `试玩新枪与扫描海岸.cmd`，直接拿新枪查看海岸。第二主武器槽现为 Poly Haven 的 7.62 栓动步枪（4K PBR、原配瞄准镜），破冰船新增扫描岩壁、80m 雪原与甲板积雪。1/2 选枪，X 切换，右键镜内瞄准，R 装填栓动步枪。来源、尺寸、技术卡与未完成项见 [资产接入记录](Unreal/FactoryRaid/Art/WEAPON_TERRAIN_ASSETS.md)。

主武器 1 保留 **HK416 + EOTech XPS3 全息瞄具**；MK18 仍可从原有搜刮内容取得。重启启动脚本后生效。仍沿用现有手臂与射击骨架，详情见 [HK416 接入说明](Unreal/FactoryRaid/Tools/HK416_README.md)。

新增独立地图 **破冰船**：双击 `启动破冰船.cmd`。包含作业甲板、机舱、船员舱、上层船桥、六名敌人和六个搜索箱。现支持双栏搜刮界面、逐个搜索、尸体搜刮和原创 FAST 风格头盔。仍是可玩原型，敌人和枪械尚未换成完整写实资产；不能视为塔科夫级成品。详见 [破冰船进度与限制](Unreal/FactoryRaid/ICEBREAKER.md)。

双击 `启动工厂.cmd` 或 `试玩UE工厂.cmd`，会打开 UE 并自动进入当前试玩。`打开UE工厂.cmd` 用于编辑地图。已经打开的旧编辑器窗口不会自动更新 Python 控制与新资源。

当前 UE 版本包含 MK18 风格枪模、镜内 SpecterDR 风格分划、Shift 放低枪冲刺、搜刮、PMC 敌人及声音。完整说明与限制见 [UE 试玩说明](Unreal/FactoryRaid/README.md)。

## 旧版 Godot 原型（以下仅介绍旧版）

这是现有 Godot 项目的可玩重构，采用经典 Factory 的公开地图作为布局参考。地图比例、距离、掩体尺寸和武器参数为重新实现与估算，**尚非《逃离塔科夫》一比一复刻**，不含原版地图资产、角色、动画或音效。

## 启动

旧版使用 `启动旧版Godot.cmd`，点击“进入工厂”。无需联网。它是固定起始装备的离线练习模式，六名 AI；每次重新部署会重新获得练习装备。成功带出的物品写入本地仓库记录。以下内容不代表 UE 版本已经实现相同功能。

## 当前实际内容

- 经典工厂分区：三层办公室（走廊、更衣/淋浴区、办公区）、中央四罐区、东侧叉车车间、蓝色货箱、高架猫道、三个地下入口和地下绕行通道。
- Gate 3 双门免费撤离；Gate 0、Cellars 需要工厂紧急出口钥匙。移除了旧版保险丝供电任务。钥匙可在二层夹克搜到。连续停留 7 秒撤离，离开重置；20 分钟行动时限。
- 移动加速/制动惯性、滚轮步速、负重减速、冲刺体力及恢复延迟、举枪体力、屏息、受伤减速、蹲伏/匍匐实体碰撞、探头墙体检查。
- 弹匣与膛内弹独立；战术换弹保留旧匣，快速换弹丢出旧匣并可拾回；散弹逐发填入备用弹匣；检查弹匣只报告大致余量。枪械操作期间不能射击。
- 半自动/全自动、举枪延迟、冲刺后射击延迟、可恢复后坐力、呼吸晃动、枪口贴掩体阻挡、带速度与重力的逐帧扫掠子弹。AI 使用同样的子弹，取消概率直接扣血。
- 头/胸/腹/双臂/双腿七部位生命，关键部位致命、护甲耐久与简化穿透、失血、损毁肢体；医疗包治疗需时间，绷带仅止血，普通医疗不能恢复损毁部位。
- 6×5 占格背包，点击物品后使用/丢弃/旋转，重量影响行动；搜刮距离、视线与墙体检测，移动打断搜索；尸体可搜索背心与武器。
- 抛掷、碰撞、延时引爆手雷，墙壁阻挡爆炸伤害；本人与 AI 的空间脚步/枪声。
- 烘焙导航网格用于 AI 绕障，AI 可以打开未锁的门；视野、听声调查、交战、搜索最后位置。
- 部署/阵亡/撤离界面；成功存档使用 `user://classic_stash.json` 和 `user://last_raid.json`，测试使用独立临时文件。

## 操作

| 输入 | 操作 |
| --- | --- |
| WASD、Shift、Space | 移动、冲刺、跳跃 |
| 滚轮 | 调节步速 |
| C、X、Q/E | 蹲伏切换、匍匐切换、左右侧倾 |
| 左键、右键、Alt | 射击、瞄准、瞄准时屏息 |
| B、R、双击 R | 快慢机、战术换弹、快速换弹 |
| Alt+R、Alt+T | 检查弹匣、检查膛内 |
| P | 逐发装填备用弹匣 |
| F / 按住 F | 开关/解锁门、站定搜索容器 |
| T、G | 手电、准备并投掷手雷 |
| 4 或 H | 使用医疗包 |
| Tab / Esc | 装备与健康界面；战局继续 |
| O / 双击 O | 显示剩余时间与撤离点 |

## 检查

```text
Godot --headless --fixed-fps 60 --path . --script res://tests/factory_smoke.gd -- --test
```

检查实际上下楼/通道/门碰撞、导航、物理和逻辑键盘输入、弹药守恒、医疗与关键部位、搜刮防隔墙、子弹和手雷遮挡、撤离条件及结算。测试不写入正式仓库。

引擎截图命令：`Godot --path . -- --preview`；另可添加 `--office`、`--tunnel` 或 `--pack`。这些预览固定镜头并冻结 AI。正常启动有完整 AI，停在部署菜单等待玩家开始。
