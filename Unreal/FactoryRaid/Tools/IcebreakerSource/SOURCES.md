# Icebreaker asset provenance

- `SM_IcebreakerHull.obj`, `SM_Deck.obj`, `SM_IceFloe.obj`: original generated environment meshes; source is `../generate_icebreaker.py`. No commercial game files used.
- `metal_plate_*_2k.jpg`: Poly Haven, Rob Tuytel, CC0. https://polyhaven.com/a/metal_plate — https://polyhaven.com/license . Actual diffuse, roughness and DirectX normal texture files are imported, not preview renders. Tile width is 50 cm as stated by the author.
- Existing character and MK18-style assets remain the project's prototype assets. They have **not** been replaced by a photoreal character/weapon pack.
- Candidate replacement (not downloaded or imported): Quantum Modular Character Free Sample, official listing https://www.fab.com/listings/8e200050-3158-4762-b297-f785b5b1533d . Listing includes a UE5-skeleton character and weapon static meshes. Its own Fab license applies; it is not CC0.
