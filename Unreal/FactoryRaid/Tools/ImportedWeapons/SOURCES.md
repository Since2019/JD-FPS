# Imported HK416 and EOTech XPS3 assets

Retrieved 2026-09-09 from https://github.com/AsmundSchei/WeaponCollection

Imported directories: `Content/Game/Assets/Models/Weapons/HK416` and `EOTechXPS3Scope`.
The repository declares CC0-1.0 and describes these as Sketchfab models collected by Asmund Schei. Its README requests artist credit, but these two asset folders contain no artist credit files. Original artist identities and the original per-model licenses have not been independently established. Preserve this provenance limitation when redistributing; do not describe these as internally authored or official licensed HK/EOTech assets.

The HK416 is an imported skeletal mesh with body and iron-sight material sets, including base color, normals, roughness, metalness and ambient occlusion. The EOTech is an imported static mesh with body textures and a separate window material slot. Neither is extracted from Escape from Tarkov.

Local adaptations: UE5 asset resave, mounting transforms, player weapon-variant switching and a custom view-direction-based holographic ring/dot material. Existing project firing/hand rig remains in use; no new professionally authored HK416 reload animation is included.
