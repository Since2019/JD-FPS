# 资产技术卡：名称 / 版本 / 日期

1. **真实尺寸估计**：长×宽×高（cm）、尺度锚点、来源、误差与未知部分。
2. **建模拆分方案**：主体、结构件、装配件、透明件；可动/静态边界。
3. **高模重点**：倒角、连接与装配、烘焙来源；标明已做/待做。
4. **低模重点**：轮廓、拓扑、变形、法线；预算与实际统计分开。
5. **UV 方案**：UV0、重叠/镜像、独特损伤区域、接缝、烘焙 padding、光照 UV 是否需要。
6. **Texel Density**：px/cm 目标、第一人称观看距离、测量结果。
7. **材质层级**：基材→涂层→有依据的接触磨损→环境沉积。
8. **Roughness 范围**：逐材料列值；哪些属于估计、哪些由实测/贴图得到。
9. **贴图分辨率**：Base Color / Roughness / Metallic / Normal / AO，色彩空间、打包与缺失项。
10. **LOD / Nanite 策略**：适用性、屏幕阈值、透明件例外，验收状态。
11. **UE5 材质设置**：着色模型、混合、双面、法线类型、参数与采样器。
12. **碰撞设置**：玩家、投射物、交互范围；可视模型是否碰撞。
13. **性能预算**：三角形、材质槽、draw calls、纹理内存、屏幕占比、测试硬件/RHI；未实测明确标注。
14. **最终真实性检查清单**：尺寸、轮廓、装配、UV/烘焙、材质、局部磨损、第一人称、曝光、碰撞、性能、来源；每项 PASS / FAIL / 未验证。
