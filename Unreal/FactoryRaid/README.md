# UE 工厂战术试玩

新增双栏 UMG 搜刮界面：对准附近箱子或击倒后的 PMC 尸体，按一次 F 打开；右侧物品逐个揭晓，点击转移，或收取全部已发现物品。左侧为 6×5 背包和重量。Tab / Esc 关闭，搜索时战局继续。拿走的物品不会在重开界面后恢复；背包放不下的物品保留。尸体保留到本轮结束，不再随模板 NPC 清理而消失。支持按住左键拖动物品到背包/搜刮格子或装备槽。FAST 头盔拖入头部槽后佩戴，拖回背包即可摘下；主武器 1 / 2 分别装备 MK18，关闭界面后按数字 1 / 2 切换，弹量独立保存。初始步枪在槽 1，槽 2 留空供搜刮所得步枪装备。空槽无法开火或瞄准。无效放置保留原物品；向已占用装备槽放置时，旧装备退回来源背包（空间不足则取消）。当前只有 MK18 一种可用枪型，两个槽共用同一枪型的表现与射击蓝图；尚无护甲防护数值。

人物新增原创 FAST 风格高切头盔、侧导轨、前置支架、魔术贴和固定带。枪械改用分部件材质细节，布料降低粗大织纹的凸起。仍是现有原型模型的改进，不是授权品牌资产，也没有达到塔科夫的角色美术质量。

使用根目录 `试玩UE工厂.cmd` 启动编辑器内试玩。`打开UE工厂.cmd` 打开编辑器，默认关卡为 `ClassicFactoryVisual`；点击播放后自动接入战术控制。已经运行的旧窗口需要重新打开。原 `ClassicFactoryTactical` 地图保留；新版材质和细节网格保存在 `Content/Factory/Visual2`。

此版本使用 Epic 第一人称射击模板的角色、手部握姿和功能步枪蓝图，出生自动装备步枪。玩家和六名 PMC 的可见枪身现为原创 MK18 风格短步枪：棕色四面导轨护木、上下机匣、短枪管、伸缩托、握把与弯弹匣。旧模板枪的可见网格被透明遮罩替代，保留握点、枪口和功能蓝图；不是授权品牌成品模型。

| 操作 | 功能 |
| --- | --- |
| WASD / Shift | 移动 / 放低枪冲刺 |
| 鼠标左键 | 射击 |
| 按住鼠标右键 | 举枪对齐实际瞄具，保持场景视野，降低移动速度 |
| 按住 Q / E | 左右探身，靠墙限制偏移 |
| 对准箱子或尸体，按 F | 打开搜刮界面；逐个检查物品并点击转移 |
| Tab / Esc | Tab 打开背包；Tab 或 Esc 关闭界面 |

关卡包含六名敌人，可巡逻、发现玩家、循枪声追踪并开火。敌人有正面视野范围、约 0.45 秒持续目视反应时间、转身速度限制与三发点射后的停顿。使用局部避障，尚无完善的多层寻路。玩家和敌人使用真实蓝图弹丸造成伤害。搜刮物品进入 6×5 格背包，已搜过的容器不会重复发放物资。

探身同时移动视点与持枪姿态，Q 向左，E 向右。场景 FOV 保持 90 度；现在有独立镜体，以及附着在镜内平面上的 SpecterDR / CX5395 风格分划，包括中央红点、粗细十字线、下方刻度与圆圈和侧方测距梯。模板屏幕中心白点已隐藏，弹药数量显示在战术文字 HUD。镜内使用独立的 512×512 HDR 实时视图和轻微边缘暗角，分划合成在同一镜片材质上；保留渲染历史，只在举镜时更新。当前为 1x，没有实现 4x 切换或远距离刻度的弹道标定。

瞄准与探身使用按帧时间计算的指数过渡。玩家武器停用模板的瞬时镜头后坐力和开火蒙太奇，由同一组临界阻尼弹簧控制轻微抬枪、后移与连续回正，避免几套动画同时校正引起抖动。鼠标转向保持直接响应。

手臂使用首次求值后的持枪握姿，暂停模板移动 IK 和骨架动画，用相机局部空间里的同一套姿态驱动手臂、枪和镜体。消除了逐帧重置世界位置再读动画插槽的反馈，也修正了模板相机的 0.3 倍组件缩放。当前未实现完整持枪步行动画和换弹动作。

Shift 配合移动进入冲刺：程序化动作围绕握持位置放低枪，并加入小幅周期摆动；不晃动瞄准相机。冲刺优先于右键瞄准，期间禁止开火，停跑后平滑恢复。独立的 `IMC_TacticalWeapons` 保留其他模板武器映射，把射击交给同一个运行时状态控制，避免第一发绕过冲刺限制；未修改原映射资产。

屏幕准星不再仅做一次透明处理：运行时每 0.2 秒检查并移除模板 HUD，关闭本机鼠标指针；战术文字 HUD 与镜内分划保留。`启动工厂.cmd` 已统一到 UE 入口，旧 Godot 原型改由 `启动旧版Godot.cmd` 打开。

照明扩展了高处灯具的实际覆盖范围，分别调整主厂房、办公室和地下通道的光强；曝光带有限制，关闭运动模糊。墙面和地面分别使用 Poly Haven CC0 扫描贴图，包含独立法线和粗糙度，按世界尺寸投射；金属和布料使用独立材质，不再套用混凝土图片。来源记录在 `Tools/SurfaceSource/SOURCES.md`。

敌人现在使用步枪和原创 PMC 装束：布料军服、头盔、面罩护目镜、携板背心与弹匣袋、背包、手套、护膝和靴子。装备跟随模板人形骨架动画；这是原创原型造型，并非塔科夫角色资产或写实成品人物。

新增背心缝线与肩带、扣具、电台和天线、腰部杂物袋、背包拉链；袖管和裤腿改为有收口和不规则褶皱的网格，布料使用织纹法线和非方格迷彩。

制服、背心和面罩进一步使用 Poly Haven 的布料扫描颜色细节、法线和粗糙度；袖裤网格改为展开的圆柱 UV，避免单位网格放大后织纹被拉伸或无法辨认。头盔独立采用哑光涂层。人物基础造型仍是原型，扫描织物并不等于完整写实人物。

弹丸使用高速扫掠碰撞和重力，隐藏原模板泡沫弹外形。枪口闪光由实际弹药消耗触发；弹着痕迹由真实弹丸停止后的表面检测生成，金属表面附带短暂火星。特效采用数量受限的原型网格效果池，并非成品级烟尘、弹壳或血液系统。

枪声跟随实际弹药消耗，敌人枪声具有距离衰减与空间定位；同时接入脚步、命中、举枪衣料和搜刮开合声。枪声使用 Epic 模板音源的项目内副本，短促交互声由本项目合成。PIE 配置为与编辑器共享音频设备，并绕过本机编辑器应用级音量抑制：测试证实未绕过时混音录音会变为静音。没有修改 Windows 音量或输出设备。

经典工厂分区来自项目已有的估算布局，包括办公室、储罐、地下通道和猫道；不是原版地图精确复刻，也未达到塔科夫的美术和枪械手感。战术换弹、部位伤害和完整撤离循环尚未接入。

当前战术功能通过 `Tools/tactical_runtime.py` 的 Python 编辑器 tick 控制，必须在编辑器 PIE 中运行，不能以 `-game` 或独立打包游戏方式运行。电脑尚无 C++ 编译工具，原生代码保留在工程外的 `../NativeGameplay`，未编译验证。

`Tools/arm_factory.py` 从基础关卡生成带枪关卡，并调用 `finish_starting_weapon.py` 安排角色初始化后的自动拾取。`Tools/test_starting_weapon.py` 在独立 PIE 中检查自动装备和开火后的弹药变化，结果写入 `Tools/weapon_test.json`。

`Tools/prepare_tactical.py` 生成战术关卡，`Tools/prepare_aim.py` 准备瞄准动画蓝图。`Content/Python/init_unreal.py` 为正常编辑器播放接入战术功能，`Tools/play_tactical.py` 为试玩入口自动开始 PIE。

`Tools/test_presentation.py` 记录连续射击的逐帧镜头变化、回正与瞄具误差，验证 PMC 装备及步枪，并录制真实引擎混音检查其非静音。人物检验截图临时增加补光，只用于看清装备。报告为 `Tools/presentation_test.json`，混音为 `Tools/combat_mix.wav`。`generate_presentation_assets.py` 生成原创装备 OBJ 与短音效，`prepare_presentation.py` 将其导入项目。

`Tools/generate_optic_details.py` 生成镜体和装备细节；随后运行 `Tools/prepare_look.py` 创建新版材质和地图。`Tools/test_look.py` 在真实移动和转头期间测量相机坐标系内的手部漂移与瞄准误差，并渲染腰射、瞄准、PMC 和地下通道。该测试不添加临时照明，截图反映地图的实际灯光。

## 拖拽与姿态更新

拖拽保留精确鼠标抓取点，物品照片随鼠标移动；绿色/红色预览表示当前落格有效/无效。物品格、装备槽和拖拽预览使用实物参考照片，照片来源见 Tools/PhotoSource/SOURCES.md。步枪照片为早期 CQBR 配置，和当前 MK18 三维模型并非完全一致。照片替换仅影响界面。

数字 1 / 2 选择两个主武器槽，X 在两槽间切换，切换有短暂放低/抬枪过渡。C 切换蹲下/站立，Z 切换趴下/站立；视角高度平滑过渡，蹲下、趴下分别降低速度和碰撞体高度，低姿态禁用冲刺，上方有障碍时阻止起身。背包底部也提供切枪、蹲下、趴下的可点击按钮。当前姿态为程序过渡及基础身体姿势，尚无完整第三人称蹲走、匍匐动作捕捉动画。

拖放修复：按下时使用鼠标按下坐标，拖动/释放使用实时桌面鼠标经游戏视口换算后的坐标，避开 Slate 捕获鼠标期间控制器位置冻结。已用真实鼠标拖动验证头盔和第二主武器装备；背包内支持数字 1/2 或点击武器槽切换。销毁的 NPC / 特效 UObject 包装器统一安全检查，避免死亡后终止整个试玩。验证记录：Tools/native_equipment_verified.json。
